Create a modern premium website named "IlllURITHM" for utility and productivity tools website and create a floating navbar consisting of sections VIDEO, AUDIO, PDF, CONVERTERS and when hover on any of the section the tools list should be dropped down for respective section. Tools names are given in the TOOLS.txt and also create icons for each tools and sections. And at to top left corner keep the logo of Illlurithm given to you Illlurithm.png
